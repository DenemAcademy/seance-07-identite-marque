Prompt à copier - trouver un nom
Propose 20 noms de marque pour mon projet.

Contexte :
- Secteur : [TON_SECTEUR]
- Cible : [TA_CIBLE]
- Offre : [TON_OFFRE]
- Style souhaité : court, mémorisable, professionnel.

Contraintes :
- 2 à 3 syllabes si possible
- facile à dire au téléphone
- pas de jeu de mots compliqué

Classe les noms par style : premium, tech, simple, agence.
