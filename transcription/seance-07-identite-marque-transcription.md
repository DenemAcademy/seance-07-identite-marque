# Séance 07 - Identité de marque - Transcription pédagogique

La transcription brute complète est dans `seance-07-identite-marque-transcription.txt`.
Ce fichier reprend les passages importants sous une forme corrigée et exploitable pour construire le support.

## 00:00:01 - 00:01:19 - Objectif de la séance

Je lance la séance 7 sur le design. Je crée un logo pour un profil freelance ou pour une agence. Après la séance 6, le QG d'organisation existe déjà avec ses dossiers, dont `00-brand`. À la fin, je veux obtenir un logo et un mini brandbook avec le nom de marque, la couleur, le chemin du logo et les règles principales.

## 00:01:19 - 00:02:35 - Le design reste subjectif

Je garde cette séance volontairement simple. Le design dépend de chaque projet et de chaque positionnement. Mon objectif est de montrer une méthode rapide : choisir trois informations, générer une première version, évaluer, corriger et ranger.

Les trois informations à préparer :

- nom de marque
- couleur principale
- style visuel

## 00:02:35 - 00:05:21 - Première génération avec Gemini

Je passe dans Gemini, en mode création d'image. Je prépare un prompt en français pour créer un logo professionnel. Dans l'exemple, je travaille sur une agence IA pour la restauration et je choisis le nom RestIA.

Le prompt demande un style minimal, vectoriel plat, des lignes nettes, un fond blanc, une typographie sans serif moderne et une seule version propre.

## 00:05:21 - 00:08:52 - Évaluer et itérer

Je laisse Gemini générer la première version. Je regarde le symbole, la police et le rendu général. La première version me plaît, surtout le monogramme R, mais je veux ajouter du vert pour enrichir la palette. Je demande donc une itération couleur sans changer toute la direction.

## 00:10:00 - 00:10:46 - Sauvegarde et attention au watermark

Quand le logo convient, je peux faire clic droit puis enregistrer l'image. Je dois vérifier le fond blanc, l'éventuel marquage de génération et le fait que le logo soit bien exploitable comme fichier final.

## 00:10:58 - 00:12:46 - Focus ChatGPT / GPT Image

Je teste aussi ChatGPT avec le même prompt pour comparer. Je repars d'un nouveau chat, je colle le prompt, puis j'attends la génération. ChatGPT produit une version correcte et rapide. Je regarde si le symbole peut fonctionner en favicon et si le nom RestIA est lisible.

Je relance ensuite une version avec le vert. Le résultat ne garde pas exactement le jaune demandé, mais le vert peut mieux servir l'identité, avec un côté plus naturel. Je peux donc garder cette version si elle est meilleure pour la marque.

## 00:12:46 - 00:13:56 - Décision et rangement

Je choisis une seule version. Je l'enregistre dans `mon-business/00-brand/`, puis je renomme le fichier avec un nom clair, par exemple `logo-agence-restia.png`. Le fichier doit être prêt à servir dans le site web, LinkedIn et les supports suivants.
